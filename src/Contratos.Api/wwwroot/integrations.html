Integrações

Conecte o seu CRM ou ERP: crie e envie contratos pela API e receba um aviso no seu sistema quando alguém assina.

Documentação da API

A API e os webhooks fazem parte do plano Empresa

Com eles, o seu sistema cria contratos a partir de um pedido ou de uma proposta, acompanha as assinaturas e baixa o PDF assinado, sem ninguém copiar dados de uma tela para outra.

Ver planos

Chaves de API

Cada sistema usa a sua chave. Ela cria e envia contratos em nome de quem a criou.

Webhooks

Endereços do seu sistema que recebem os eventos dos contratos, assinados com um segredo.

Entregas recentes

Cada evento é tentado até 8 vezes, por cerca de 2 dias, até o seu sistema responder com sucesso (2xx).
